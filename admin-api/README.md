# このPCの作品管理

作品サイトはGitHub Pagesのままです。この管理アプリはこのPCのループバックアドレスでだけ動作します。

## 開く

`start-admin.cmd` をダブルクリックし、管理画面にログインします。公開サイトのDCCロゴからも、このPCの `http://127.0.0.1:5090/admin/` に移動できます。ほかの端末からこのPCの管理画面へアクセスする構成ではありません。

初回のパスワードはこのPCの `.env.local` にハッシュで設定済みです。ほかのPCで使う場合は `python set_password.py` を実行してください。パスワードの平文をサイトやリポジトリに書かないでください。

## 編集と公開

1. 各作品の売り切れ・説明文・価格を編集し、「保存する」を押します。
2. 保存した内容はこのPCの `data/catalog.sqlite3` と、隣の `gallery/works.json` に記録します。
3. 「GitHubへ公開」を押すと、`kqede0113/ar-card` の `gallery/works.json` だけを更新します。既存のモデルやサイトは変更しません。
4. GitHub Pagesの公開処理が終わると来場者にも反映されます。開いたままの作品サイトは20秒おきに情報を確認します。

保存だけではGitHubの公開サイトは更新されません。公開処理の結果は画面に表示します。

## GitHubの初回ログイン

このPCのGitHub CLIに作品リポジトリへの書き込み権限が必要です。

```powershell
gh auth login --hostname github.com --web --git-protocol https
```

ブラウザーで本人がログインを完了してください。アプリは必要なときだけ `gh auth token` で認証情報を取得し、公開コードには保存しません。認証できない場合は公開に失敗したことを管理画面に表示し、保存済みの編集はこのPCに残します。

## 保存データ

`.env.local` と `data/` はGit管理対象外です。このPCのバックアップに含めてください。元のカタログは `catalog.json` にあり、モデルを追加する際はこれも更新します。価格などの編集はデータベースを優先します。

手動起動: `python server.py`。既定ポートは5090です。外部へ公開する必要はありません。
