# DCC 作品ギャラリー

公開先: https://kqede0113.github.io/ar-card/gallery/

STL/3MFから作成したGLBをmodel-viewerで表示する静的サイトです。作品データはworks.json、表示用モデルはmodels/、サムネイルはposters/にあります。元のSTL/3MFとG-codeは公開しません。

サル・ペンギン・ふくろう・ワンちゃん・猫の説明文は、作者の指示でSketchfabの公開投稿から移行しました。鹿は投稿が見つからなかったため、作品名に基づく短い説明を置いています。

model-viewerはjsDelivrから読み込みます。モデルは作品を選んだときだけ取得し、最初から全作品をダウンロードしません。
